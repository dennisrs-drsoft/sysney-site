# Notas unificadas — 19/10/2026

Publicação autorizada pelo usuário, somente Next/SWA. Preserva a release comercial e documentos do acompanhamento. Versão preparada 2026.10.19.003; preparação não comprova publicação.

- Notas fiscais e XML reúne o arquivo fiscal importado e referências fiscais de mensagens originais de cobrança da mesma empresa. Mescla pelo número exato normalizado; avisos e rascunhos sem nota ficam fora. Não associa empresas diferentes.
- PDF histórico quando disponível; na ausência, usa o anexo protegido da cobrança. XML apenas quando realmente importado. Nada é emitido, cancelado ou enviado.
- Fonte histórica prevalece para data, valor e situação fiscal, inclusive cancelamento. Registro apenas na cobrança fica identificado como tal, sem data fiscal inventada. Datas de competência/e-mail não são usadas como emissão.
- Busca normalizada por número, razão social, documento, contato e destinatário; Twenty Four Seven também pesquisável por TFSeven. Alias é só busca, não vínculo financeiro.
- Datas ausentes podem permanecer no filtro de período por opção explícita, ativada inicialmente. Ordenação, paginação e filtros preservados; botão para limpar filtros. Falha de uma fonte não oculta registros da outra; modal padrão para erro. Troca de empresa não mostra dados antigos sob novo contexto.

Build completo, TypeScript e lint direcionado aprovados; 16 testes específicos aprovados na implementação. Validação visual autenticada ainda não realizada. Nenhuma mudança em API externa, VM, certificados ou DNS. Scripts operacionais excluídos dos commits. Evidência de publicação será acrescentada ao término.
